# public/media — marketing & SEO images

Drop images for the marketing site here. Files in `public/` are served from the
site root, so `public/media/foo.jpg` is reachable at
`https://amqualitysystems.com/media/foo.jpg` and referenced in code as
`/media/foo.jpg`.

## Naming (matters for image SEO)

Use descriptive, lowercase, hyphenated, keyword-aligned names. The filename is a
ranking signal for Google Images.

- ✅ `iso-9001-certification-uganda.jpg`
- ✅ `iso-lead-auditor-training-kampala.jpg`
- ❌ `IMG_2043.jpg`, `photo1.png`, `Screenshot 2026-07-09.png`
